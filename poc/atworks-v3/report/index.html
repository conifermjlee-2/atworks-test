+ AI 결합 파이프라인

단순히 코드를 읽는 것을 넘어, AST(정적 분석)와 실제 API 구동 로그를 LLM에 주입하여, 완벽한 사용자 여정(User Journey) 기반의 E2E 테스트 시나리오를 자동으로 구축합니다.

프론트엔드 소스 분석(AST) 작동 원리

Static Analysis Engine
1 Babel AST 파싱

JSX/TSX 소스코드를 런타임 실행 없이 AST(추상 구문 트리) 구조체로 변환합니다. 모든 컴포넌트, Hook, 함수 호출부를 노드 단위로 정밀 추적합니다.

2 Action → API 맵핑

버튼 클릭(onClick), 폼 제출(onSubmit) 등의 사용자 액션 핸들러 내부에서 호출되는 fetch, axios, useQuery 식별자를 바인딩합니다.

3 Evidence Graph 생성

화면 경로(Route) → 사용자 액션 → API 엔드포인트 → 전송 타입(Payload)으로 이어지는 연관 관계 그래프를 도출하여 LLM 입력 프롬프트로 변환합니다.

시나리오 with AI

프론트엔드 소스코드의 정적 구조(AST)와 네트워크에서 캡처된 실제 API 로그를 융합하여 LLM이 사용자 행동 기반의 테스트 스텝을 역추적합니다.

API 테스트 전이(Chaining) 탐지

프론트엔드 코드 내부의 API 간 논리적 연쇄 호출(ex. 생성 후 갱신, 종속 데이터 호출) 패턴을 AST 기반으로 완벽하게 추적하여 연결고리를 도출합니다.

RQ

onSuccess 연쇄

react-query의 useMutation 성공 콜백 내 invalidateQueries 패턴을 감지하여 이어지는 GET 요청을 자동으로 연결합니다.

RTK

invalidatesTags

Redux Toolkit Query의 뮤테이션 시 무효화되는 캐시 태그를 매핑하여 관련된 데이터를 재조회하는 흐름을 찾아냅니다.

HOOK

useEffect 의존성

useEffect 의존성 배열에 이전 API 결과값이 포함된 경우, 라이프사이클에 따른 순차 호출 시나리오를 구성합니다.
