# 프론트엔드 API 시나리오 분석기 v7 (get-front-code-7)

React/Next.js 프로젝트 코드를 정적 분석(AST)하고, 누락된 문맥을 로컬 LLM이 추론하여 비즈니스 시나리오를 자동 생성하는 도구입니다.

## 주요 기능
- **AST 파싱 및 정적 분석**: 프론트엔드 코드의 라우트, API 호출 포인트, Trigger 요소를 자동으로 추출합니다. (`Detected` 마킹)
- **로컬 LLM 추론**: 추출된 AST 데이터를 바탕으로 에이전트가 비즈니스 문맥을 추론하여 기획서 수준의 마크다운 리포트를 작성합니다. (`Inferred` 마킹)
- **에이전트 브릿지 서버**: 웹 클라이언트에서 분석을 요청하면, 백그라운드 태스크가 감지하여 IDE 에이전트(AI)가 분석을 수행하고 화면에 결과를 푸시(SSE)합니다.

## 설치 및 실행 방법

### 1. 패키지 설치
```bash
npm install
```

### 2. 프로젝트 실행
```bash
npm run dev
```

### 3. 에이전트 감시 스크립트 실행 (중요)
브라우저에서 분석을 요청했을 때 에이전트를 깨우기 위해서는 **반드시** 백그라운드에 감시 스크립트가 실행되고 있어야 합니다.
(IDE 환경에서 백그라운드 태스크로 실행해두어야 합니다.)
```bash
node waitForRequest.js
```

## 사용 방법
1. 브라우저에서 `http://localhost:3000` 에 접속합니다.
2. 분석할 대상 프론트엔드 프로젝트의 **절대 경로**를 입력합니다. (또는 '더미 경로 로드' 버튼 클릭)
3. **분석 실행** 버튼을 클릭합니다.
4. 백그라운드에서 에이전트가 코드를 분석하고, 진행 상태가 UI에 실시간으로 반영됩니다.
5. 분석이 완료되면 "AST 추출 데이터 (IR)" 탭에서 JSON 포맷의 구조화된 데이터를, "AI 비즈니스 시나리오 리포트" 탭에서 마크다운 리포트를 확인할 수 있습니다.
6. 진행 중인 분석은 **중지** 버튼을 클릭하여 취소할 수 있습니다.
